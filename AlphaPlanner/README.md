# Alpha Planner Android

Phase-1 personal finance Android app scaffold.

## Build
GitHub Actions builds a debug APK from the `alpha-planner-build` branch through PR CI.

## Current features
- Jetpack Compose + Material 3
- Home, Transactions, Plan, News, AI tabs
- Day/Week/Month/Year dashboard selector
- Demo finance data and transaction categories
- Five-theme engine
- Android API 36 target for stable CI

## Next
Room database, notification transaction capture, merchant classification, reminders, settings, AI integration, news feeds, biometric security.
